# PictureView - Home Assistant Addon

Security camera image viewer with timeline and auto-delete.

![PictureView](https://img.shields.io/badge/Home%20Assistant-Addon-blue)

## Features

- Browse camera images sorted by creation time
- Timeline panel grouped by day (right sidebar)
- Auto-delete images after 1-365 days
- Dark/light mode
- Keyboard navigation (← →)
- Auto-refresh every 60 seconds

## Installation

1. Add this repository to Home Assistant: `Settings → Add-ons → Add-on store → ⋮ → Repositories`
2. Install **PictureView**
3. Configure `image_folder` to point to your camera images
4. Start the addon
